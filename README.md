# Minecraft Mod Support

Shared support for all Minecraft mods maintained by **misemise8**.

Have a bug to report, a feature to suggest, or a question about a mod?
[Open an issue](https://github.com/misemise8/minecraft-mod-support/issues/new/choose) and choose the matching form.
Enter the mod's name as shown on its download page. You can report any of my mods here, including new ones.

| Contact type | Form |
| --- | --- |
| A crash, unexpected behavior, or compatibility problem | [Bug report](https://github.com/misemise8/minecraft-mod-support/issues/new?template=bug_report.yml) |
| An improvement or new feature | [Feature request](https://github.com/misemise8/minecraft-mod-support/issues/new?template=feature_request.yml) |
| Installation, settings, or general help | [Question](https://github.com/misemise8/minecraft-mod-support/issues/new?template=question.yml) |

For bug reports, include the mod version, Minecraft version, loader, what happened, and how to reproduce it if known.
Screenshots and relevant logs are welcome. Search [existing issues](https://github.com/misemise8/minecraft-mod-support/issues) first in case the same problem has already been reported.

**English and Japanese are welcome.** Replies and follow-up information stay in the issue thread.

This repository is a shared support hub. Download each mod from its own project page.

## 日本語

misemise8が開発するすべてのMinecraft Modの共通問い合わせ窓口です。
[問い合わせを作成](https://github.com/misemise8/minecraft-mod-support/issues/new/choose)から、不具合報告、機能の要望、質問のフォームを選んでください。
対象Modの名前は配布ページに表示されている名前を入力してください。
一覧への登録を待たず、新しいModについても問い合わせできます。

不具合報告には、Modのバージョン、Minecraftのバージョン、ローダー、起きたことを記入してください。
分かる場合は再現手順を、必要に応じて画像やログを添えてください。
日本語での問い合わせも受け付けます。
